# 图片描述自动填写

## 目标

让发帖预填工具在上传图片后，自动填写豆瓣图片下方的“添加描述（选填）”字段。

## 输入格式

图片块支持可选的 `description` 字段：

```json
{
  "type": "image",
  "path": "materials/images/room.jpg",
  "description": "客厅采光与沙发区域"
}
```

`description` 未提供或为空白字符串时，工具不填写图片描述。提供时必须是字符串，且会去除首尾空白。

## 行为

1. 上传图片并等待图片已插入、上传状态消失。
2. 若该图片块存在非空 `description`，定位刚插入的 `.DRE-image` 节点，点击其 `.DRE-caption-input-placeholder.empty` 占位段落。
3. 点击后，该节点会生成 `textarea.DRE-input[placeholder="添加描述（选填）"]`；只在该图片节点范围内对 textarea 填写描述。
4. 随后继续后续图片或文本块。

上传或描述填写失败时，沿用既有的图片失败占位和继续填充行为；工具不点击发布。

## 实现边界

`normalizePost` 负责格式校验，`fillBlocks` 将完整图片块传给上传回调，浏览器上传函数负责定位并填写描述输入框。描述输入框严格限定在刚插入的 `.DRE-image` 节点内，避免误填其他图片的描述。

## 测试

覆盖以下行为：

- 图片块可接受并规范化非空描述；空白描述会被忽略。
- 图片插入回调接收图片路径和描述。
- 描述填写逻辑仅在提供描述时执行。
