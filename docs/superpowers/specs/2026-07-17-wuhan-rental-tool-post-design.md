# 武汉租房小组经验帖设计

## 目标

生成并预填一篇武汉租房小组宣传帖，以正在看房的武汉租房者口吻介绍小程序，而非直接广告。

## 叙事与语气

以“看了几套房后，价格记得住，通勤和缺点反而记混了”为开头。先描述租房决策中的真实信息整理困难，再介绍作者为自己做的工具。避免夸大、保证性表述和虚构使用数据；不将示例截图中的价格、房源名或路线数据当作真实武汉房源。

## 内容结构

1. 标题：武汉看房几套后，我做了个不靠记忆的看房记录工具。
2. 解释房源照片、聊天记录和地图信息分散带来的比较困难。
3. 按“看房时容易漏什么、工具如何解决”介绍六个模块：房源基本信息、房屋检查、公区检查、通勤、周边和房源对比。
4. 房源基本信息记录面积、楼层、电梯、支付方式、租期和租住渠道，避免后续比较时遗漏成本与条件。
5. 房屋检查记录采光、通风、噪音、气味等现场感受；公区检查记录入口、楼道、雨天与夜间通行、环境和安全；每项都可补备注。
6. 通勤以目的地为基准查看公交、驾车和骑行；周边集中记录配套；对比页并排呈现多套房的差异。
7. 结尾邀请同样在武汉看房的人试用并反馈，附小程序码。

## 图片与发布边界

- 使用 `房屋基本情况-费用信息.jpg`、`房屋基本情况.jpg`、`公区检查.jpg`、`通勤-公交方案详情.jpg`、`周边.jpg`、`房源对比通勤.jpg` 和 `小程序码.jpg`。
- 每张图写准确的说明文字。
- 将文章写到 `output/post.json`，随后用 `npm run fill` 预填到武汉租房小组的新帖子页；不点击发布。
