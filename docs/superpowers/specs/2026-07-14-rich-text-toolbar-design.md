# 富文本工具栏映射设计

## 范围

`post.json` 支持豆瓣富文本工具栏中除“添加条目”和“条目卡片”外的功能。脚本继续只预填草稿，绝不点击发布。

## 数据格式

支持以下块类型：

- `paragraph`：普通文字，可附加 `bold`、`highlight`、`strikethrough`、`align: "center"`、`block_highlight` 和 `soft_breaks`。
- `heading`：标题。
- `quote`：引用。
- `ordered_list`、`unordered_list`：使用非空字符串数组 `items`。
- `divider`：分割线。
- `link`：链接文字与 HTTPS URL。
- `image`：本地图片及可选描述。

`soft_breaks` 是字符串数组；数组元素会在同一文本块内由“软回车”分隔。

## 纯编辑器模式

脚本不输入 Markdown，所有格式均通过对应的豆瓣工具栏按钮实现：标题、加粗、高亮、删除线、有序/无序列表、居中、引用、块高亮、分割线和软回车。图片仍沿用上传流程；链接、添加条目和条目卡片不实现。

## 执行方式

每个文本块先启用其所需的 `.DRE-action-button`，再写入纯文字；行内格式随后关闭，避免影响下一块。图片继续沿用已验证的上传 URL 与描述绑定机制。

## 校验与错误处理

JSON 解析会拒绝未知块类型、空列表、非 HTTPS 链接和不合法样式字段。脚本只在对应按钮可见时执行；按钮找不到或操作失败时终止该草稿且不发布。测试覆盖 JSON 规范化、工具栏动作顺序及列表/软回车写入。
