# V2EX 租房助手产品介绍帖设计

## 目标

以小程序开发者的第一人称，在 V2EX 介绍租房记录与现场看房小程序，邀请社区成员体验并提供具体反馈。文章使用 Markdown，可直接复制到发帖编辑器。

## 标题

做了一个租房看房记录小程序，想请 V 友帮忙体验和拍砖

## 叙事与语气

- 从“多看几套房后，信息散落在聊天记录、相册和地图里，难以比较”这一问题切入。
- 明确作者是产品开发者，不假装普通用户或第三方推荐者。
- 语气坦诚、克制、便于交流，不使用“解决行业痛点”“颠覆”“全网最好”等夸张表达。
- 不虚构用户量、使用效果、具体房源、租金或开发经历。
- 技术栈只用于交代开发背景，不展开为技术教程。

## 内容结构

1. 开场：说明开发动机和看房信息难以统一整理的问题。
2. 产品流程：录入房源、现场检查、查看周边与通勤、对比两套候选房源。
3. 核心能力：房屋与公区检查、费用记录、常用目的地、公交/驾车/骑行路线、周边配套、房屋/公区/周边/通勤对比。
4. 技术背景：uni-app、Vue 3、TypeScript、Pinia、uniCloud、腾讯地图。
5. 当前状态：产品仍在迭代，邀请真实体验，不宣称已经充分验证。
6. 反馈问题：功能是否容易理解、记录项是否过多、现场是否愿意使用、缺少哪些关键能力。
7. 体验入口：文末放小程序码。
